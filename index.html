snapcheck

Snapshot a folder to a hash manifest, verify it later. Answers the question "did anything in here change — or silently rot?"

Do this today

npm i -g @snapcheck/cli

snapcheck snap ~/Documents    # snapshot -> ~/Documents/.snapcheck.json
snapcheck chk  ~/Documents    # 0 unchanged / 1 changed / 2 error

What it catches

  • Bit rot — same size + mtime but a different hash is silent data corruption.
  • Change — added, modified, or missing files, one command.
  • Backup verify — snapshot the source, confirm the copy matches.
